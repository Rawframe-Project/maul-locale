# Where the library's segmentation departs from ICU4C 79.1 on the cases of
# test/segment_icu.tsv, each line a reason, then the case: locale, kind
# and text. test_segment fails on a difference not listed here and on a
# line that no longer differs. The library follows CLDR's segments files;
# each departure is ICU4C's own data or rules, not CLDR's
# (docs/user/segmentation.md#differences-from-icu4c).
#
# zh-default  ICU4C's zh and zh_Hant line default is its strict line_cj;
#             CLDR's zh.xml gives normal, CJ as an ideograph.
# ko-default  ICU4C tailors Korean lines with its own data, normal by
#             default; CLDR has no Korean segments file, so Korean takes
#             the root's strict lines.
# cj-quotes   ICU4C's _cj line rules, for Chinese, Japanese and Korean with
#             -u-lb and zh's default, make U+201C OP and U+201D CL.
# cj-wave     ICU4C's line_normal_cj and line_loose_cj take U+301C and
#             U+30A0 out of NS, so a line may break before them.
# ja-words    ICU4C finds Japanese words with its own dictionary; CLDR's ja
#             rule 13.3 keeps a Hiragana run one word (rule 13.4, the
#             ideographs, waits for Maul Unicode's Ideographic property).
